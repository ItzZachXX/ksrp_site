# Kentucky State Roleplay website

Static site for GitHub Pages. No folders: every file sits at the top level of the repository.
It talks to the bot's API (running on BisectHosting) at the address in config.js.

Files: index.html, departments.html, portal.html, 404.html, site.css, site.js, portal.js, config.js, logo.png, CNAME, .nojekyll

1. Upload all of these files to the root of a GitHub repository (including CNAME and .nojekyll).
2. Settings, Pages: deploy from the main branch, root. Custom domain: kentuckyrp.xyz. Tick Enforce HTTPS.
